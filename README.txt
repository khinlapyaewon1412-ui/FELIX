FELIX PORTFOLIO WEBSITE

Files:
- index.html: responsive portfolio website
- assets/profile-photo.png: supplied beige-blazer portrait
- assets/Felix_Financial_Accountant_CV.pdf: supplied resume for download

Preview locally:
1. Extract this folder (if using the ZIP).
2. Open index.html in Chrome, Edge, Firefox or Safari.

Publish with Netlify:
1. Go to https://app.netlify.com/drop
2. Drag the Felix_Portfolio_Website folder (or the ZIP after extracting it) into the upload area.
3. Netlify will publish the site and provide a public URL.

Keep the assets folder beside index.html. Do not upload index.html by itself, or the photo and CV download links will not work.
